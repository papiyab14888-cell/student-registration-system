# Student Registration System

## Description
A web-based application developed to manage student records. [cite_start]It allows users to register students with their name, ID, email, and contact details, with full CRUD (Create, Read, Update, Delete) capabilities[cite: 3, 4].

## Features
- [cite_start]**Persistent Storage**: Uses Local Storage to ensure data remains after page refreshes[cite: 31].
- [cite_start]**Validation**: Strict input validation for ID (numbers), names (characters), and email formats[cite: 32].
- [cite_start]**Responsive Design**: Optimized for mobile, tablet, and desktop screens[cite: 25].
- [cite_start]**Dynamic UI**: Includes a dynamic vertical scrollbar for the record section[cite: 34].

## How to Run
1. Clone the repository or download the ZIP file.
2. Open `index.html` in any modern web browser.

## Technologies Used
- [cite_start]HTML5 (Semantic tags) [cite: 47]
- [cite_start]CSS3 (Flexbox/Grid and Media Queries) [cite: 25]
- [cite_start]JavaScript (DOM Manipulation and Local Storage) [cite: 26, 31]
